# 已知限制

本页记录当前版本的真实边界，避免文档承诺超过实现。问题修复后应同步删除对应条目。

## 平台与构建

- 仅支持 Windows x64；未验证 MSVC、Linux、macOS。
- 运行需要 OpenGL 4.5；虚拟机、远程桌面或旧驱动可能无法创建上下文。
- 提供 per-user Setup 安装程序，也支持直接使用运行目录；暂未提供 MSIX 或系统级安装包。
- 未做代码签名；SmartScreen 可能提示未知发布者。

## 图片

- 支持静态 PNG、JPEG、WebP；不支持 GIF、动画 WebP 或 APNG。
- JPEG 会读取 EXIF Orientation；PNG/WebP 的方向信息不处理。
- 单图默认上限 3000 万像素，可在设置中调整为 400–20000 万像素；超限图片在解码前被拒绝。
- 图片解码、缩略图生成仍在 UI 线程执行，极大图片或多选大量图片时可能短暂卡顿。
- 不提供裁剪、旋转或全局调色。
- 导出只针对当前任务，不支持批量导出。

## 深度模型

- 仅支持 1 个输入、1 个输出。
- 输入按 NCHW `1×3×H×W` 解释；输出按单通道浮点深度解释。
- 支持 FLOAT32 / FLOAT16；INT8、Q4 等量化模型不支持。
- 固定输入尺寸模型只能使用与其匹配的推理分辨率。
- 多输入/多输出模型（例如 Depth Anything V3）会在加载时被拒绝。
- 不自动下载、转换或量化模型；模型错误由 ONNX Runtime 返回。
- 手动推理分辨率只对动态尺寸模型安全。
- 预处理重采样使用 stb_image_resize2 近似 PIL；与 Python 侧结果不会逐像素一致。
- DirectML 不可用或驱动异常时依赖 CPU 回退；CPU 推理明显更慢。

## 渲染与导出

- 最多 8 盏灯；局部灯光控制通过聚光灯与独奏实现，暂未提供画笔蒙版。
- 聚光灯的阴影仍使用点光阴影近似，光锥内的可见性没有单独的锥形阴影贴图。
- 深度平滑、阴影柔化等参数影响预览与导出，但不存在物理正确的全局光照。
- 物理光照使用 GGX/Smith/Schlick 的屏幕空间近似，没有 IBL 或光线追踪；材质高光依赖深度法线，可能比离线渲染更平滑。
- 颜色纹理 mipmap 会轻微柔化表面细节亮度；不适合显微级纹理。
- 16 位深度 PNG 使用 stored-deflate，不压缩；高分辨率导出文件会明显偏大。
- 导出使用原图分辨率，显存不足时可能失败；失败会显示状态栏错误。
- 透明像素的最终光照表现取决于输入 alpha 与渲染混合，不保证与所有 DCC 软件一致。
- 预览分辨率与导出分辨率不同，极细阴影在预览中可能看不出来。

## 资源与配置

- 任务数量默认上限 100（最大 500），内存预算默认 4 GB（最大 16 GB）。
- 配置写在 exe 同级的 `config.json`；安装到只读目录时保存会失败并提示。
- 程序不写注册表、不写 AppData。
- 模型检查、SHA-256 与 PNG 编码是异步的；退出时会等待未完成的导出。
- 模型首次检查需要加载 DLL 与模型，可能耗时数秒，期间界面显示「检查中…」。
- 撤销/重做只保留当前进程内的外观编辑，不写入磁盘；关闭程序后历史清空。
- 安装器升级保留已有模型文件与 `config.json`，不会用安装包内同名文件覆盖用户模型。

## 界面

- 高 DPI 缩放使用启动时的 content scale；运行中切换显示器 DPI 不会重新布局。
- 中英文覆盖 UI 文案；底层 I/O 与 ONNX Runtime 的错误文本可能为英文。
- 没有多窗口、分屏或浮动面板。
- 设置对话框是模态的，打开时不能操作主界面。

## 测试与环境

- GPU 金图像依赖具体驱动/实现，允许 PSNR 误差；无 OpenGL 4.5 时测试标记为 SKIP。
- CI 环境通常没有 DirectML GPU，因此 DirectML 路径主要依赖本机手工验证。
- 金图像测试覆盖固定场景，不能替代真实图片的人工检查。
