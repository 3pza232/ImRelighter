# 使用

## 图片

- 支持 PNG、JPEG、WebP。
- `Ctrl+O` 或左侧「打开图片」；可多选，每张图一个任务。
- 也可把一张或多张图片直接拖进窗口，或把图片路径作为命令行参数：`ImRelighter.exe a.png b.jpg`。
- JPEG 会按 EXIF Orientation 自动旋转；PNG/WebP 不做方向推断。
- 单图默认上限 3000 万像素，可在设置中调整为 400–20000 万像素；超过时在解码前拒绝，避免异常文件占用大量内存。
- 安装目录、图片路径可以包含中文和空格。

## 任务

- 点击任务卡任意位置切换任务；右侧 `×` 关闭。
- 每个任务独立保存图片、深度、灯光、材质、渲染参数与视图。
- 右栏「表面与合成」顶部可复制当前任务外观，再切到其他任务粘贴覆盖；快捷键为 `Ctrl+Shift+C` / `Ctrl+Shift+V`。复制内容包括材质、光照、表面和灯光，不包含图片、深度、视图与缩放。
- `Ctrl+Z` / `Ctrl+Y` 在当前进程内撤销/重做外观编辑，包括复制粘贴、灯光与材质调整；切换任务后各自保留历史，关闭程序后清空。
- 任务数量默认上限 100，内存上限默认 4 GB，可在设置中调整。
- 关闭最后一张图后画布回到空状态，状态栏不再显示旧文件名。

## 深度

- 设置中可选 `Auto / CPU / DirectML`；Auto 优先 DirectML，不可用时回退 CPU。
- 右栏「生成深度与法线」或 `Ctrl+G`。
- 取消按钮会请求终止当前推理；过期结果不会写回任务，即使切换到其他任务。
- 推理在后台线程执行，取消期间界面保持响应；模型加载阶段可能需要等待当前加载完成。

## 模型

- 设置 → 模型 →「选择模型文件」，选择任意本地 `.onnx`。
- 「打开模型目录」打开当前模型所在目录。
- 「取消选择模型」清除当前模型并进入未选择状态。
- 模型类型（fp32 / fp16）由后台检查权重精度得出；检查期间显示「检查中…」。
- 模型检查失败会在模型页显示错误，不再沿用上一个模型的类型。
- SHA-256 由程序在后台按模型文件（含外部数据）计算。
- 大模型的 `model.onnx` + `model.onnx_data` 必须放在同一目录，选择 `model.onnx` 即可。

更多兼容性说明见 [models.md](models.md)。

## 画布

- 7 个视图：光照、对比、原图、法线、深度、仅光照、阴影。
- 滚轮以鼠标为中心缩放；中键拖动平移；`F` 适应窗口。
- 左键点击画布任意位置会把当前选中的灯移过去并开始跟随拖动；点击灯光标记可直接选中该灯。灯光可以移到图片外。
- 自动环绕在拖动灯光时停止。

## 右栏

- 图像与深度：模型状态、推理设备、推理分辨率、生成/取消。
- 灯光：最多 8 盏，添加、删除、复制、开关、独奏与列表选择；独奏只保留选中灯参与照明。
- 灯组预设：三点、窗光、轮廓，一键替换当前灯组。
- 选中灯光：位置 X/Y/Z、颜色、强度、范围；类型可选点光或聚光，聚光支持光锥角度与柔化。
- 明暗与表面：环境光、曝光、法线强度、深度平滑、阴影步数、柔化、分辨率等。
- 表面细节：用原图亮度的高频分量补充法线微纹理，默认 0.15。它只保留细小的织物、发丝和皮肤纹理，宽大的烘焙阴影会被带通差分抵消；细节采样使用颜色纹理的 mipmap/LOD，避免把 JPEG 噪声放大成白色闪点。调到较高值时仍可能放大硬边，建议按图调节。
- 渲染方案：自然、人像、电影、经典，一键切换光照模型、高光、边缘光、曝光与色调映射。
- 光照模型：物理使用 GGX/Smith/Schlick，适合肤色、布料与金属感；经典使用 Blinn-Phong，接近 0.2.0 的观感。
- 色调映射：柔和保持中间调，电影使用 ACES 并适合更强的明暗对比。方案与模型只修改当前任务的参数。
- 材质：默认、皮肤、布料、头发、金属预设；可再细调粗糙度、金属度、光泽与次表面。物理光照下这些参数直接影响 GGX 高光与漫反射，经典光照下也会调整高光宽度与色调。

推理分辨率可选手动值仅对动态尺寸模型安全；静态输入模型应使用自动或与模型一致的尺寸。

## 设置

`Ctrl+,` 或右上角「设置」。设置是模态对话框，打开时背景不可交互，`Esc` 关闭。

- 外观：暗色 / 亮色主题。
- 语言：简体中文 / English，立即生效并写入配置。
- 推理后端：Auto / CPU / DirectML。
- 资源：任务数量上限、内存上限；拖动时只更新界面，松开后写盘。
- 模型：选择/清除、路径、类型、大小、SHA-256。
- 关于：版本与许可证。

## 导出

顶部「导出」或 `Ctrl+E`：

- 光照 PNG
- 法线 PNG
- 深度 16 位灰度 PNG
- 仅光照 PNG
- 阴影 PNG

导出使用原图分辨率重新渲染。GL 回读在主线程完成，PNG 编码异步执行；导出期间按钮禁用。16 位深度 PNG 使用 stored-deflate，文件较大但兼容性好。

## 快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl+O` | 打开图片 |
| `Ctrl+G` | 生成深度与法线 |
| `Ctrl+E` | 导出 |
| `Ctrl+Z` | 撤销当前任务的外观编辑 |
| `Ctrl+Y` | 重做 |
| `Ctrl+Shift+C` | 复制当前任务外观 |
| `Ctrl+Shift+V` | 粘贴外观到当前任务 |
| `Ctrl+,` | 打开设置 |
| `F` | 适应画布 |
| `Esc` | 关闭设置 |

## 配置

- 配置写入 exe 同级的 `config.json`。
- 保存失败时状态栏显示错误，而不是静默丢失。
- 配置读取对缺失字段使用默认值，并保留本版本不认识的字段；安装器覆盖升级不会替换 `config.json`。
- 程序不联网、不上传图片、不下载模型。
