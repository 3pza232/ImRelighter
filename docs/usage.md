# 使用

## 图片

- 支持 PNG、JPEG、WebP。
- `Ctrl+O` 或左侧「打开图片」；可多选，每张图一个任务。
- 也可把图片路径作为命令行参数。

## 深度

- 设置中可选 `Auto / CPU / DirectML`。
- 右栏「生成深度与法线」或 `Ctrl+G`。
- 取消按钮会终止当前推理；过期结果不会写回任务。

## 模型

- 设置 → 模型 →「选择模型文件」，选择任意本地 `.onnx`。
- 「打开模型目录」打开当前模型所在目录。
- 「取消选择模型」清除当前模型并进入未选择状态；按钮为红色。
- SHA-256 由程序在后台按模型文件（含外部数据）计算。
- 大模型的 `model.onnx` + `model.onnx_data` 必须放在同一目录，选择 `model.onnx` 即可。

## 界面

- 7 个视图：光照、对比、原图、法线、深度、仅光照、阴影。
- 滚轮缩放、中键平移、左键拖动灯光。
- 自动环绕：拖动灯光即停止。
- 暗色/亮色主题、中英文即时切换。

## 导出

顶部「导出」或 `Ctrl+E`：

- 光照 PNG
- 法线 PNG
- 深度 16 位灰度 PNG
- 仅光照 PNG
- 阴影 PNG

GL 回读在主线程完成；PNG 编码异步执行，导出期间按钮禁用。
