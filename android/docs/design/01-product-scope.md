# Android 产品范围与目标

> 状态：Draft，供 Android MVP 设计与实现使用。正式发布前应重写为产品文档。
> 上级索引：`../README.md`

## 1. 产品定位

Android 版 ImRelighter 是桌面版的移动端重打光工具，面向单张人像/角色图片的本地处理：

1. 从系统相册或文件选择器导入图片。
2. 在设备本地运行深度估计模型，生成深度图。
3. 基于深度图生成法线图，并与原图、材质设置一起参与光照。
4. 通过触摸调整灯光、阴影、材质与视角。
5. 导出最终图片或分享到其他应用。

所有推理与渲染均在设备本地完成，不上传用户图片。

## 2. MVP 范围

MVP 必须完成：

- 单图导入：JPEG、PNG、WebP。
- 深度推理：默认 q4 模型，arm64 CPU。
- 深度/法线预览：原图、深度、法线、光照四种视图。
- 基础重打光：至少 1 个主光，支持位置、强度、颜色、阴影开关。
- 材质参数：高度、法线强度、细节、平滑、反照率/材质类型的最小集合。
- 触摸交互：画布拖动、双指缩放/平移、灯光选中与拖动。
- 导出：PNG/JPEG 保存到系统选择的位置或分享。
- 设置：语言、主题、推理线程数、模型选择（从应用私有目录导入）。
- 错误处理：模型缺失、图片过大、推理失败、导出失败。

## 3. 明确不做（MVP）

- 多图批处理与项目文件。
- 云端推理、账号、同步。
- 8 灯完整桌面工作流、复杂预设管理、撤销栈全量对齐。
- 完整桌面三栏布局的像素级复刻。
- 桌面安装器、GLFW、DirectML、Windows 文件对话框的复用。
- 首版支持 32 位 ABI。

## 4. 非功能目标

| 项目 | 目标 |
| --- | --- |
| 最低系统 | Android 8.0 / API 26 |
| 目标系统 | API 36 |
| 默认 ABI | `arm64-v8a`，调试构建额外 `x86_64` |
| 图形 API | OpenGL ES 3.1 起，优先 3.2 |
| 语言 | C++20 + 薄 Kotlin 宿主 |
| 单图上限 | 首版 12 MP（后续按内存策略调整） |
| 深度推理 | 1080p 级输入在主流 arm64 设备上 < 4 s |
| 交互帧率 | 预览稳定 30 FPS，目标 60 FPS |
| 崩溃率 | 发布前无已知必现崩溃 |
| 包体 | 首版 arm64 APK 目标 < 100 MB |

## 5. 成功标准

- 在至少 2 台 arm64 真机上完成导入、推理、法线、光照、导出全流程。
- q4 模型在真机上不出现 q4f16 的轮廓密集噪点。
- 法线/深度方向正确，与原图方向一致。
- 旋转、后台切换、Surface 重建后状态不丢失。
- 大图不会 OOM；失败时给出可操作的错误提示。
- 桌面版与 Android 版共享算法语义，但代码通过明确的移植边界维护。

## 6. 版本策略

Android 版使用独立版本号，不与桌面版强绑定。

- `android` 目录内维护 `versionCode`/`versionName`。
- 首个可安装验证版本建议 `0.1.0`。
- 桌面版模型/算法更新通过 `android/docs/design/appendices/desktop-parity.md` 记录差异。
- 发布产物放入忽略目录 `android/dist/`，不提交二进制。

## 7. 关键依赖

- Dear ImGui 1.92.5：UI。
- stb_image / stb_image_resize2：图片解码与缩放。
- ONNX Runtime Android 1.20.0：CPU 推理。
- 深度模型：q4，27,404,416 bytes，默认路径
  `models/depth-anything-v2-small/q4/model_q4.onnx`。
- Android NDK 26.3、CMake 3.22.1、AGP 9.0.1、Gradle 9.1.0、JDK 17。

## 8. 待确认
