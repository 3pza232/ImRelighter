# 06 · UI/UX 设计

## 目标

把桌面版的单图重打光能力压缩成适合手机的操作流，而不是把桌面三栏界面等比缩小。移动端用户通常单手操作、屏幕窄、没有鼠标悬停和右键，因此交互必须重新设计。

## 信息架构

MVP 顶层只保留四个区域：

1. **画布**：显示原图/深度/法线/照明结果；
2. **视图切换**：Original / Depth / Normal / Light；
3. **参数抽屉**：灯光、材质、法线、导出；
4. **全局动作**：打开、导出、设置、撤销/重做。

桌面端右侧 Inspector 的多个面板改为底部抽屉或全屏面板，避免在竖屏下挤压画布。

## 布局

### 横屏 MTV

- 中央画布占主要空间；
- 左侧窄工具栏（视图切换、灯光列表）；
- 右侧可折叠参数抽屉（宽度约 320dp）；
- 顶部标题/文档名，底部状态栏。

### 竖屏

- 画布占上半部；
- 底部固定标签栏：视图 / 灯光 / 材质 / 导出；
- 参数以 bottom sheet 覆盖，不永久占宽；
- 重要按钮位于拇指可触区。

MVP 优先横屏；竖屏作为支持但非首要验收。

## 触控交互

- 单指拖动：平移画布；
- 双指捏合：缩放；
- 双指拖动：画布旋转仅在后续版本考虑，MVP 不做；
- 点击灯光标记：选中灯光；
- 长按/拖动灯光标记：移动灯光；
- 双击画布：适配/1:1；
- 滑块：与桌面数值一致，增加当前值显示和 reset；
- 所有可点击目标至少 44×44dp；
- 禁止依赖 hover；触控状态要有按下/选中反馈；
- 返回键：先关闭抽屉/菜单，再退出；
- 系统栏使用 edge-to-edge，画布内容避开刘海/手势区。

## 视图与状态

- Original：原图；
- Depth：归一化深度，附范围；
- Normal：q4 深度生成的法线；显示必须与桌面方向一致；
- Light：最终照明结果；
- 推理中显示进度/取消，不冻结 UI；
- 文档切换保留每张图的参数；
- 错误以可读中文/英文提示，不显示裸 GL/ORT 错误码；
- 首次启动引导：打开图片，不允许直接空白画布。

## 灯光编辑

MVP 支持：

- 添加/删除灯光；
- 选择灯光；
- 位置 X/Y/Z；
- 颜色、强度、半径/硬度；
- 阴影开关；
- 预设：夕阳、月光、舞台；
- 灯光列表显示编号和颜色，编号颜色自适应亮度。

移动端不直接复制桌面快捷键体系；快捷键只作为外接键盘增强。

## 材质与法线

- 材质：粗糙度、金属度、高光强度/硬度、环境光；
- 法线：强度、细节、平滑、翻转；
- 高级参数默认折叠；
- 修改参数只触发重绘，不重新推理；
- 推理只在打开图片/重新生成深度时发生。

## 导出

- 选择 PNG；
- 默认使用当前视图；
- 显示分辨率、估计大小；
- 导出走 SAF `CreateDocument`；
- 完成后可分享；
- 大图导出显示进度，可取消；
- 失败保留错误信息。

## 字符串与本地化

- 中英文同步维护；
- 所有可见文案放入资源，不在 C++ 中硬编码；
- 尺寸/数量使用本地化格式；
- 语言切换后立即刷新 UI；
- 新增 key 必须有中英文，测试校验 key 集合一致。

## 可访问性

- 对比度满足基本可读性；
- 不仅用颜色表达选中状态，增加边框/图标；
- 字号随系统字体缩放（在布局允许范围内）；
- 重要操作有文本标签，不只图标；
- 支持外接键盘 Tab/Enter/Esc（后续）。

## 验收

- 1080×1920 与 1440×3200 两类屏幕无控件重叠；
- 单手可完成打开 → 调灯 → 导出；
- 画布手势不误触参数；
- 中英文切换无缺失；
- 横竖屏切换不丢文档/参数；
- 关键路径无鼠标依赖。
