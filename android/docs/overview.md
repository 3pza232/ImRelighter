# 项目概览

> 让一张图在手机上拥有可编辑的光。

ImRelighter Android 读取 PNG/JPEG/WebP 图片，使用内置或用户选择的 ONNX 深度模型估计深度，在 OpenGL ES 中构造高度场、法线和阴影，并实时渲染最多 8 盏点光/聚光。所有计算都在设备本地完成。

## 产品定位

- **单图重打光**：一次处理一张图，但可以同时保留多个任务并快速切换。
- **桌面算法移动端移植**：深度平滑、法线、光线步进阴影和光照使用与桌面版一致的 shader 语义。
- **触摸优先**：竖屏布局、单指画布平移、双指缩放、拖动灯光标记、滑块拖动和可滚动参数面板。
- **结果可导出**：光照、法线、深度、仅光照、阴影五种 PNG 导出。
- **完全离线**：不申请网络权限，不上传图片，不自动下载模型。

## 功能模块

| 模块 | 职责 |
|---|---|
| Kotlin `MainActivity` | `SurfaceView` 宿主、系统栏、相册/文件选择器、MediaStore 导出 |
| `app/` | `AndroidApp` 生命周期、任务、UI 布局、参数、渲染 Pass 调度 |
| `core/` | 视图模式、灯光、`LightingSettings`、深度结果、模型目录 |
| `ml/` | ONNX Runtime 推理、模型配置、预处理、深度归一化/缩放 |
| `io/` | 图片解码与资源读取 |
| `platform/` | JNI 桥、EGL/GLES 上下文和 Surface 生命周期 |
| `ui/` | Dear ImGui 主题、字体、可复用控件与触摸路由 |

## 数据流

1. Kotlin 从相册读取图片，解码为 top-down RGBA8，通过 JNI 交给原生层。
2. 原生层创建任务，上传原图纹理；用户点击“生成深度与法线”后，后台线程运行 ONNX 推理。
3. 深度结果归一化到 `0..1`，保持 top-down 方向，生成 `DepthResult`。
4. GPU 深度/高度 Pass：`depth_smooth.frag` 的 GLES 移植把深度写入 R32F 高度纹理，应用自动/手动深度范围、平滑、反转和线条辅助。
5. 法线 Pass：由高度和原图生成 RGBA16F 法线（不支持时回退 RGBA8），alpha 保存边缘遮罩。
6. 阴影 Pass：两组 RGBA8 目标分别处理 0–3、4–7 号灯，光线步进后做边缘感知模糊。
7. 光照 Pass：读取原图、法线、高度、阴影，按经典/物理模型、柔和/ACES tone mapping 输出到预览纹理；导出时按原分辨率重新渲染。
8. Kotlin 通过 MediaStore 把 PNG 写入 `Pictures/ImRelighter`。

## 关键约束

- 渲染使用 OpenGL ES 3.1；最低 Android 8.0（API 26）。
- 默认模型 `depth-anything-v2-small/q4/model_q4.onnx` 随 APK 分发，约 27 MB。
- 单任务参数与结果保存在进程内存；进程被杀后任务清空。主题、语言、模型选择和模型目录持久化。
- 最多 8 个任务，任务上限可在设置中调整（默认 8）。
- 预览长边默认 1536；显示预览可降采样，导出始终使用原图尺寸。
- 阴影光线步进默认 96 步、4 采样、半分辨率（divisor 2）；拖动参数时暂缓阴影更新，松手后刷新。
