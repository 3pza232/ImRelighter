# 使用

## 导入图片

- 支持静态 PNG、JPEG、WebP。
- 点击画布中的“导入图片”或左上角任务栏的 `+`，从系统相册/文件选择器选择图片。
- 每张图创建一个任务；导入前会按设置中的任务上限检查（默认 8）。
- 图片解码在后台线程执行；超大图片会被采样到合理尺寸，避免内存峰值。
- 原图以 top-down RGBA8 保存，方向不做 EXIF 旋转以外的推断。

## 任务

- 点击左侧 `»` 打开任务抽屉；点击任务行切换，右侧红色 `×` 删除。
- 每个任务独立保存：图片、深度、灯光、材质、光照参数、阴影参数、视图、画布缩放/平移。
- 切换任务时会重建高度、法线、阴影和光照 GPU 数据；不会出现上一个任务的深度/阴影残留。
- 任务只保存在进程内存中。按 Home 再回来（进程未死）任务仍在；强制停止、卸载或进程被杀后从空状态开始。
- 删除最后一个任务后画布回到空状态。

## 生成深度与法线

- 选择任务后，在右下方“图像与深度”卡片点击“生成深度与法线”。
- 推理在后台线程执行，状态栏显示“正在生成深度与法线…”。
- 完成后原图视图自动切换到光照；如果当前已选择其他视图（如法线/深度），推理完成后保留该视图。
- 一个任务的推理不会覆盖另一个任务；切回时恢复该任务自己的结果。
- 推理失败会在状态栏显示错误；纹理上传失败也会显示错误。

## 视图

| 视图 | 内容 |
|---|---|
| 原图 | 解码后的输入图，用于对比 |
| 光照 | 合成后的重打光结果 |
| 法线 | 由高度场生成的法线可视化 |
| 深度 | 高度/深度场可视化 |
| 阴影 | 当前选中灯的可见性图 |
| 仅光照 | 去除原图底色后的光照贡献 |

所有非原图视图都经由同一个光照合成 shader 输出；法线和深度也会受到深度幅度等合成参数影响。

## 画布

- 单指拖动平移；双指捏合缩放；画布适应窗口。
- 点击画布会把当前选中的灯移动到点击位置并开始跟随拖动。
- 灯光标记显示编号；标记颜色与灯光颜色对应。
- 灯光可以移动到图片外。

## 灯光

- 右下“光源”卡片可添加灯光、选择灯光、启用/关闭、编辑位置 X/Y/Z、颜色、强度、范围。
- 灯光类型：点光 / 聚光；聚光可调角度和柔和度。
- 最多 8 盏灯；超过 8 盏时只渲染前 8 盏。
- “当前灯光”行用于选择要编辑的灯。

## 光照与阴影参数

- 环境色、环境光、环绕光。
- 启用阴影、阴影偏移、阴影柔和、阴影步数、采样数。
- **显示阴影步进**：开启后直接显示光线步进的原始可见性图（不经过边缘模糊），可以观察/保留步进与硬边效果；关闭时使用模糊后的柔和阴影。该开关默认关闭，只影响光照 Pass 的采样来源，不改变阴影计算本身。
- 高光、光泽硬度（Shininess）、轮廓光。
- 经典/物理光照模型；柔和/ACES tone mapping。
- 仅使用重打光结果、效果混合、曝光 EV。

## 表面与合成参数

- 法线强度、表面细节。
- 边缘平滑：驱动 `depth_smooth` 的平滑核；拖动时使用 3x3 快速核，松手后使用完整核。
- 线条辅助：平滑时参考原图颜色边缘。
- 反转深度。
- 材质预设：默认、皮肤、织物、头发、金属；影响粗糙度、金属度、光泽、次表面等。
- 糙度、金属度、光泽（Sheen）、次表面、深度幅度。
- 翻转 X/Y/Z、自动深度范围、深度最小/最大。
- 预览长边：限制显示用光照目标尺寸；导出始终使用原图分辨率。

## 导出

点击顶部“导出图片”，选择：

- 光照 `_relight.png`
- 法线 `_normal.png`
- 深度 `_depth16.png` 名称的 PNG（实际为 RGBA8 PNG，非 16 位）
- 仅光照 `_lighting.png`
- 阴影 `_shadow.png`

导出通过 MediaStore 写入 `Pictures/ImRelighter`，不需要存储权限。导出时按原图分辨率重新渲染当前视图，不使用预览降采样；完成后状态栏显示“已导出”。

## 设置

- 主题：深色/浅色，持久化。
- 语言：简体中文/English，持久化。
- 模型：q4、自定义 ONNX 文件夹、模型类型、恢复默认 Q4。
- 任务上限：默认 8，可调整。
- 设置弹窗点击外部关闭；打开设置时不会误触下层画布/参数面板。

## 性能提示

- 静态画面不会重复执行 GPU Pass；拖动参数只跑必要的 Pass。
- 拖动灯光或阴影参数时阴影光线步进暂缓，松手后刷新；高度平滑在拖动时使用快速核。
- 阴影步数/采样数和预览长边是最影响性能的三个设置。真机上优先降低阴影采样数或预览长边。
- 首次生成后的第一帧需要编译阴影/光照 shader 并分配 FBO，可能有一次明显停顿；后续帧使用缓存。
